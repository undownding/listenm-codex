# 离线农历缓存

- 覆盖北京时间 2026-01-01 至 2031-12-31，共 2,191 天。
- 数据来自[香港天文台公历与农历对照表](https://www.hko.gov.hk/tc/gts/time/conversion.htm)，原始年度文本保存在 `sources/hko-YYYY.txt`。
- 2026 年与[紫金山天文台《2026年日历资料》](https://pmo.cas.cn/xwdt2019/kpdt2019/202203/P020251230620718707826.pdf)逐日独立解析、比对，365 天的农历月、日、闰月标记无差异。2027–2031 年来源为香港天文台，未标记为紫金山天文台验证数据。
- 官方来源文件保留原样，其内容归各发布机构；本项目仅转换客观历法日期供本地动画调度使用。

`calendar.json` 的 `days` 以公历 YYYY-MM-DD 为键，值为 `[农历月, 农历日, 是否闰月]`。元数据包含原始文件 URL、SHA-256，以及交叉校验范围和结果；不是 ICU 计算结果导出。

在仓库根目录运行 `python3 scripts/cache-calendar.py` 可离线重建。加 `--refresh` 才会从官方地址重新下载。转换依赖 Python 3、Poppler 的 `pdftotext`；下载使用 curl 并验证 HTTPS 证书。无运行时网络依赖或定时更新任务。

解析器会检查全年完整性、公历日期、农历逐日连续性与月转换，以及 2026 年交叉校验。PDF 版式变化时拒绝生成新缓存，不自动猜测或用计算值伪装成官方记录。范围外日期由 bridge 的 ICU 实现回退。

# Optional whale animations

Generated by `scripts/pack-extras.py` from `luweiyabo/dsh-whale-pet`, pinned source commit and shared geometry in `manifest.json`. Per-pack hashes and category list are in `catalog.json`. Source asset permission/attribution: `../../licenses/whale-assets-upstream.md` (noncommercial; not covered by the source project's MIT code license).

Binary format (little endian): `WHP2`, uint32 frame count, width, height; count+1 uint32 offsets; 512-byte RGB565 palette; frames with a uint32 color-plane byte length, PackBits palette indices, then PackBits alpha bytes. Alpha uses 16 levels (0,17,...,255); RGB565 foreground is blended over the framebuffer background. Offsets are relative to the palette start. FPS is 12. Firmware accepts 208×196 only, at most 600 frames and 1,750,000 bytes, and validates offsets before decoding. Packs share exactly the core sprite transform; no per-animation fitting.
